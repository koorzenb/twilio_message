# Email Template Test Output

This directory contains test outputs generated by the email template system.

## Files Generated

- `test_email.html` - Sample HTML email for IRCC update notification
- `test_email.txt` - Sample plain text email for IRCC update notification

## How to Test Templates

Run the template engine in test mode:

```bash
cd src
python notifications/email_templates.py
```

This will:

1. Test both HTML and text template rendering
2. Test scenarios with and without updates
3. Optionally save test outputs to files

## Template Variables

Both templates support these dynamic variables:

- `{{has_updates}}` - Boolean indicating if updates were detected
- `{{timestamp}}` - Current date/time of the check
- `{{page_title}}` - Title of the monitored webpage
- `{{target_content}}` - The specific content being monitored
- `{{last_updated}}` - Last modified date from the website
- `{{page_size}}` - Size of the webpage in bytes
- `{{notices_count}}` - Number of important notices found
- `{{website_url}}` - URL of the monitored website

### Conditional Sections

- `{{#has_updates}}...{{/has_updates}}` - Show only when updates detected
- `{{^has_updates}}...{{/has_updates}}` - Show only when no updates
- `{{#has_notices}}...{{/has_notices}}` - Show only when notices exist
- `{{#show_history}}...{{/show_history}}` - Show change history section
